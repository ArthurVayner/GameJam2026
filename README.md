# 🌱 Jack and the Beanstalk (Game Jam 2026)

A retro, Gameboy-inspired take on the classic fairytale, created for Game Jam 2026. 

🎮 **[Click Here to Play the Game in Your Browser!](https://arthurvayner.github.io/GameJam2026/)**

## 📖 About the Project
This project brings the story of Jack and the Beanstalk to life with nostalgic Gameboy-style graphics and mechanics. It was built from the ground up during Game Jam 2026 to capture the feel of classic handheld gaming.

## ✨ Features
* **Retro Aesthetic:** Authentic Gameboy pixel art style and green-tinted palette.
* **Instant Play:** Fully playable directly in your web browser—no downloads required.
* **Modern Engine:** Powered by Godot 4 and exported to HTML5.
